# Build Calculator App

## Task 1: Calculator CLI App

This project is a simple command-line calculator built using Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Input validation
- Exit option
- Menu-driven CLI interface

## Technologies Used

- Python
- VS Code
- Command Line Interface (CLI)

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python calculator.py
